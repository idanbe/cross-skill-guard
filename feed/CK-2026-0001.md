# CK-2026-0001: lethal_trifecta: imap-smtp-email

Published 2026-10-25. Rule `lethal_trifecta`. Reported in https://github.com/idanbe/cross-skill-guard/issues/1.

## Components

- imap-smtp-email (skill)

## What this means

This component can read private data, take in untrusted input and send data out, all in one agent: untrusted mail input, private mail and egress to mail via imap-smtp-email → imap-smtp-email → imap-smtp-email.

That set of capabilities is risky for an agent, because one session can use all of them in sequence without the user seeing a step in between. This page describes what the component is able to do, not why it was written.
